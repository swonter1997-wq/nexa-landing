# NEXA — AI-платформа для бизнеса

Адаптивный landing page для вымышленной AI-платформы автоматизации бизнеса.

## О проекте

NEXA — демонстрационный landing page, разработанный для практики современной frontend-разработки.

Проект включает адаптивную верстку, интерактивные элементы и базовую клиентскую валидацию формы.

## Функциональность

- адаптивная верстка для desktop, tablet и mobile;
- мобильное навигационное меню;
- плавная прокрутка между секциями;
- интерактивный FAQ-аккордеон;
- форма обратной связи;
- клиентская валидация имени и email;
- CSS-анимации;
- hover-эффекты;
- адаптивные карточки тарифов и возможностей.

## Запуск проекта

1. Клонировать репозиторий:

```bash
git clone git@github.com:swonter1997-wq/nexa-landing.git
```

2. Перейти в папку проекта:

```bash
cd nexa-landing
```

3. Открыть `index.html` в браузере.
